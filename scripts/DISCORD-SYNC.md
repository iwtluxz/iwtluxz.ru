# Синхронизация карточек Discord

Карточки на GitHub Pages читают публичные снимки
`data/discord-profiles/USER_ID.json`. GitHub Actions обновляет их по расписанию
раз в 5 минут; запуск расписания и публикация могут задерживаться. Страница
проверяет снимок раз в минуту. Это периодическое обновление, а не постоянное
подключение браузера посетителя к Discord.

## Настройка GitHub Pages

1. В Discord Developer Portal открой своего бота → **Bot** и включи
   **Presence Intent**. Для новых пользователей бот должен состоять на сервере
   `1557152366208229486`, указанном публичным полем `discordGuildId` в
   `backend-config.js`. Пользователь также должен вступить на этот сервер.
2. В репозитории GitHub → **Settings → Secrets and variables → Actions** добавь
   `DISCORD_BOT_TOKEN` (токен бота) и `DISCORD_GUILD_ID` (ID общего сервера
   исходных трёх профилей). Существующая синхронизация `iwtlu`, `shakzy` и
   `strelokk` сохраняется. Токен пользователя не нужен. Токен бота не попадает
   в HTML или JSON.
3. В **Settings → Pages** используй **Deploy from a branch**, ветку `main`,
   папку `/ (root)`. Workflow явно запрашивает пересборку Pages после автокоммита:
   коммит с `GITHUB_TOKEN` сам по себе её не запускает.
4. После загрузки изменений в репозиторий запусти **Actions → Sync Discord
   profiles → Run workflow**, чтобы проверить первый проход, не ожидая расписания.

Каждый запуск отдельно проверяет доступ бота к серверу новых карточек, даже когда
таких карточек пока нет. В журнале появляется `Discord profile guild …: available
to the bot` либо предупреждение с безопасным HTTP/API-кодом. `Unknown Guild`
не означает, что пользователь не вступил: при недоступном сервере членство
считается неизвестным. Только `Unknown Member` (`10007`) означает отсутствие
конкретного участника.

## Настройка новой карточки

В кабинете включи обновление из Discord, укажи свой **User ID**, вступи на сервер
по `discordInviteUrl` и примени изменения к странице. ID можно скопировать в
Discord после включения **Настройки → Расширенные → Режим разработчика**.
Указанный ID выбирает публичную карточку; это не OAuth-подтверждение владения
Discord-аккаунтом и не способ входа в кабинет.

Скрипт читает только опубликованные настройки с `discordSync: true`, проверяет
членство в указанном сервере и после этого запрашивает публичный профиль. Черновик
не включает синхронизацию для посетителей до публикации. Несколько страниц с
одинаковым Discord ID используют один снимок. При выходе с сервера снимок теряет
имя, аватар, статус, активность и значки; при недоступности проверки членства
состояние становится неизвестным, без автоматической карточки.

Отображаемый ник выбирается так: ник на сервере → глобальное имя → username.
При удалении статуса исчезает текст в плашке; при офлайн-статусе сохраняется
последний известный пользовательский текст. Активность игры или музыки при
офлайне скрывается. Скрытые настройками Discord активности бот получить не может.

Значки берутся из документированных `public_flags`: HypeSquad, Early Supporter,
ранний разработчик, Bug Hunter, партнёр, сотрудник и другие поддерживаемые флаги.
Server Booster добавляется только при наличии `premium_since` у участника именно
этого сервера. Подписку Nitro обычный Bot API публично не сообщает, поэтому
значок текущего Nitro не выдумывается. Неизвестные флаги не интерпретируются.
Декоративные значки профиля выбираются отдельно и не считаются наградами Discord.

Снимок содержит только перечисленные публичные поля, без ролей, секретов
активности, адресов электронной почты и токенов. Неизменённый снимок получает
свежую отметку проверки раз в 6 часов. Автоматическая карточка использует данные
не старше 24 часов. Неиспользуемые снимки удаляются только при наличии маркера
этого генератора; исходные и вручную добавленные файлы сохраняются. Если запрос
списка опубликованных страниц прерывается, очистка не запускается.

При проверке 30 октября 2026 ссылка `https://discord.gg/fnmEdMKr` указывала на
сервер `1557152366208229486` и имела срок действия до **2 ноября 2026, 07:14
(Самара)**. Для постоянного доступа замени `discordInviteUrl` бессрочным
приглашением на тот же сервер.

## Локальный запуск

Нужен Node.js 22+. Скопируй `.env.example` в `.env`, заполни два Discord-параметра
и выполни `node scripts/sync-discord-avatars.mjs`. Затем открой сайт через локальный
HTTP-сервер, например `python -m http.server 8000`, и перейди на
`http://localhost:8000/iwtlu.html?demo=1`.

Проверки: `node --test scripts/test-discord-profile.mjs`.

Документация: [публичные флаги пользователя](https://docs.discord.com/developers/resources/user#user-object-user-flags),
[участники сервера](https://docs.discord.com/developers/resources/guild#get-guild-member),
[Discord Gateway](https://docs.discord.com/developers/events/gateway-events#request-guild-members),
[запуск сборки Pages](https://docs.github.com/en/rest/pages/pages#request-a-github-pages-build).
