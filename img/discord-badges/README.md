# Discord badge assets

Original Discord artwork, stored locally and used as images. Existing core icons
were fetched unchanged from Discord's CDN. The expanded catalog uses original
current and historical Discord artwork from the sources listed below. Discord
owns the artwork. No icon is reconstructed using a generic icon set.

Server tag icons continue to use the user's real `primary_guild.badge` hash and
the documented `guild-tag-badges` CDN endpoint.

## Meaning and synchronization

The selector has 100 current and historical designs. A manually selected badge
decorates the page and does not verify ownership, a subscription, or an award.
Automatic badges remain restricted to documented public account flags and the
actual `premium_since` value for membership in this project guild. A boost in
one guild does not establish the account's global subscription streak.

Streaming achievements are ten experiment tiers based on accumulated streaming,
not the current presence being live. Account Age, Game Time, Game Variety,
gifting and Nitro milestone designs likewise cannot be inferred from bot presence.
The Bot API does not return this complete earned-badge list. Current Nitro's
`premium_type` is scoped to OAuth `identify.premium`, not public bot flags.

Official references:

- [Discord user fields and public flags](https://docs.discord.com/developers/resources/user)
- [Profile Badges 101](https://support.discord.com/hc/en-us/articles/360035962891-Profile-Badges-101)
- [Evolving Nitro Badges](https://support.discord.com/hc/en-us/articles/29136565881623-Evolving-Nitro-Badges)
