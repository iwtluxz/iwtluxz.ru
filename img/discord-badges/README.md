# Discord badge assets

Original Discord artwork, downloaded unchanged from Discord's CDN. These assets
are used as images, not reconstructed with generic SVG paths. Discord owns the
artwork. Server tag icons use the user's actual `primary_guild.badge` hash and
the documented `guild-tag-badges` CDN endpoint.
