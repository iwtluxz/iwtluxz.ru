# Оригинальные украшения Discord

В каталоге 705 уникальных украшений из объединённых открытых архивов. Это проверяемый снимок, а не гарантия наличия каждого когда-либо выпущенного или неопубликованного предмета Discord. Старые 37 идентификаторов сохранены.

Проверено 17 ноября 2026 года: все 705 хешей отдают оригинальное изображение через официальный `cdn.discordapp.com/avatar-decoration-presets/`.

## Источники каталога

- [DiscordDecoFetcher, закреплённый JSON](https://github.com/lucvxc/DiscordDecoFetcher/blob/55c6eb8e58fbb306eb1fcf413ba9743bf9a1cbd1/decorations.json): 659 записей с названиями, коллекциями и официальными хешами.
- [Discord collectibles downloader, закреплённый архив](https://github.com/JulesZYTB/discord-collectibles-downloader/tree/64fa978a5237e030474adb30b6e4eaf1b6685f18/discord_collectibles/Avatar_Decorations): дополнительные архивные оригиналы. Хеши взяты из имён исходных APNG; названия — из названий папок.
- [Discord Collectibles Archive](https://github.com/Infinitay/discord-collectibles-archive/tree/main/discord-data/collections): исторические коллекции. Точный commit записан в `data/discord-avatar-decorations.json`.
- [Официальный формат CDN Discord](https://docs.discord.com/developers/reference#image-formatting): путь `avatar-decoration-presets/{asset}.png`.

Происхождение каждой записи, название и коллекция находятся в `data/discord-avatar-decorations.json`. Изображения не являются перерисовками.

## Производительность и отображение

- В меню только неподвижные WebP из этой папки: все 705 вместе занимают около 4,9 МБ. Новые 668 превью получены напрямую с официального CDN, с параметрами `size=128&passthrough=true`. Старые превью сохранены.
- Меню показывает 48 украшений за раз, поиск и выбор коллекции работают по всему каталогу. В отличие от всех анимаций сразу это не перегружает редактор.
- Старые 37 анимаций остаются локальными PNG. Новые анимации берутся с оригинального CDN при выборе, без загрузки всего архива размером более 600 МБ.
- При ошибке CDN выбранное украшение остаётся видимым как локальное статическое превью. Повторное применение настроек не запускает бесконечные запросы.
- При отключённых системных анимациях сразу используется статическое превью.
- Если украшения нет в снимке каталога, можно вставить его официальный URL в «Другое украшение Discord». Принимается только HTTPS CDN Discord и точный путь украшения, без сторонних доменов и произвольных адресов. Сохранённый ID имеет вид `discord-a_<32 hex>`.

## Проверка и пополнение

`node scripts/sync-decoration-catalog-assets.mjs` докачивает отсутствующие превью записей из `profile-decorations.js`, проверяя формат WebP, отсутствие кадров анимации, ограничения размера и разрешённый исходный домен. Существующие файлы не перезаписываются. Новые локальные PNG анимаций массово не скачиваются.

При обновлении каталога сначала объединить новые достоверные записи с `data/discord-avatar-decorations.json`, сохраняя уникальность по `asset`. Существующие 37 ID не переименовывать; для остальных использовать `discord-` + официальный `a_<32 hex>`. Добавить строки в блок `archive-catalog` в `profile-decorations.js`, затем выполнить синхронизацию превью и `node --test scripts/test-decoration-catalog.mjs`.

Наличие предмета в этом каталоге относится к оформлению страницы iwtxz; оно не выдаёт покупку, Nitro или право использования украшения в самом Discord.
