      Discord в твоей карточке

      Для синхронизации аватарки и статуса вступи на наш сервер и укажи ID Discord. Значки можно выбрать свободно.

      Вступить в Discord ↗
      Где найти свой ID?

      В Discord открой «Настройки → Расширенные» и включи режим разработчика. Затем нажми правой кнопкой по своему профилю → «Копировать ID пользователя».

      ID: Discord → Настройки → Расширенные → Режим разработчика, затем правой кнопкой по своему профилю → Копировать ID.

      Добавь ID и вступи на сервер, чтобы включить обновление.

      Значки выбираются тобой и сохраняются независимо от синхронизации Discord.
