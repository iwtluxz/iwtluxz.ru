      Discord в твоей карточке

      Для обновления аватарки, статуса и значков вступи на наш сервер и укажи свой ID Discord.

      Вступить в Discord ↗
      Где найти свой ID?

      В Discord открой «Настройки → Расширенные» и включи режим разработчика. Затем нажми правой кнопкой по своему профилю → «Копировать ID пользователя».

      Добавь ID и вступи на сервер, чтобы включить обновление.

      Discord отдаёт только доступные боту данные и публичные значки. Закрытые значки и оформление Nitro могут быть недоступны.
