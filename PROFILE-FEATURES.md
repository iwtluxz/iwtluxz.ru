# Оформление и музыкальная библиотека

Обновление 2026-11-02: миграция `supabase/migrations/20261102_interactive_profiles.sql`
добавляет снег, дождь, матрицу, глитч, параллакс, наклон карточки, курсоры, иконку
вкладки и выбор заполнения аватара. Эффекты ограничены 30 кадрами в секунду,
останавливаются в скрытой вкладке и учитывают уменьшение движения в системе.
Для «Из Discord» в редактор передаётся только проверенное украшение свежего снимка.
В каталоге украшений показываются статичные миниатюры аватара пользователя.

Публичный домен — `iwtxz.su`, API — `music.iwtxz.su`. Логин-алиасы
`accounts.iwtxz.ru` сохраняются для совместимости существующих аккаунтов.
Каталог ищет вне стартовой подборки; доступность провайдеров и ключи API описаны
в `music-service/README.md`. Профиль использует родной iframe выбранного сервиса.

Кабинет: минимальная AMOLED-форма, ссылка `/?auth=signup` сразу открывает регистрацию.
В разделе **Эффекты** доступны 10 анимаций ника, живой образец, 8 оригинальных
украшений Discord, режим «Из Discord» и кнопка случайной пары с отменой.
Каталог использует статичные WebP-миниатюры; анимация загружается для выбранного
украшения в превью. Для текущего украшения Discord нужны включённая синхронизация,
ID и свежий снимок аккаунта. При уменьшении движения в системе анимации отключаются.

Соцсети: Discord, Telegram, Steam, VK, YouTube, Twitch, TikTok, Instagram,
GitHub, Spotify, X, SoundCloud, Reddit, Boosty и личный сайт. В кабинете —
раскрывающиеся строки, на странице — белые SVG-логотипы со свечением.

На публичных профилях через 12 секунд активного просмотра после экрана входа
однократно появляется приглашение создать свою страницу. Отметка сохраняется
в браузере на весь сайт. Кабинет и iframe-превью его не показывают.

Для существующего проекта Supabase нужны миграции по порядку:

1. `supabase/migrations/20261030_profile_customization.sql`
2. `supabase/migrations/20261030_profile_effects_and_socials.sql`

Вторая миграция сохраняет все существующие данные; повторное выполнение безопасно.
`builder_capabilities()` возвращает `profileSettingsVersion: 3`, `profileEffects: true`.
Для нового проекта достаточно актуального `supabase/setup.sql`. Библиотека музыки
использует отдельный сервер: [установка и ограничения](music-service/README.md).
API подключается через `backend-config.js` → `musicApiUrl`. Скачанный трек
автоматически выбирается в редакторе; для публичной страницы нужно нажать
**Применить к странице**. Загруженные собственные аудиофайлы также попадают в список.

Общие каталоги — `profile-features.js`; источники оригиналов — `img/PROFILE-ASSETS.md`.
Команды обновления:

```text
node scripts/refresh-feature-markup.mjs
node scripts/build-feature-migration.mjs
node scripts/sync-profile-assets.mjs
python scripts/build-decoration-thumbnails.py
npm run version:assets
```

Для пересборки миниатюр нужен Pillow (`python -m pip install Pillow`). Оригинальные
анимации не изменяются. Обычной сборке сайта Python/Pillow не требуются.

Проверки:

```text
node --test scripts/test-*.mjs
python -m unittest discover -s music-service -v
npm run build
```

Миграция исполняется в PGlite с проверкой старых данных, публикации, валидации
и изоляции аккаунтов. Музыкальный сервис проверяется через настоящий HTTP с
тестовым загрузчиком: личные списки, очередь, Range и запрет чужих изменений.
Проверки не создают облачных аккаунтов и не меняют опубликованные профили.
