# Оформление профиля

Новые поля сохраняются после применения `supabase/migrations/20261117_profile_catalog_and_layout.sql`. Файл также включает первоначальную поддержку просмотров: отдельно применять предыдущую миграцию просмотров не нужно. Существующие черновики, опубликованные страницы и счётчики не переписываются.

В разделе «Профиль» доступны два цвета градиента описания, направление и перелив с периодом 2–30 секунд. При отключённых системных анимациях градиент остаётся статичным и видимым. Обычный цвет описания применяется после выключения градиента.

Просмотры можно включить, показать текстом или глазиком, изменить цвет и размер. По умолчанию счётчик находится слева внизу на уровне плеера; на узком экране он поднимается над плеером, если иначе они пересекаются. Для перемещения включите «Переместить блоки» в превью. Сброс позиций возвращает счётчик на исходное место. Превью не увеличивает просмотры.

Каталог украшений содержит 705 оригинальных изображений из доступных коллекций Discord. Есть поиск, коллекции и страницы по 48 карточек. Превью хранятся на сайте; выбранное украшение загружается с официального Discord CDN и заменяется локальной статичной версией при недоступности CDN. Для оригинального украшения, отсутствующего в архиве, можно вставить ссылку вида `https://cdn.discordapp.com/avatar-decoration-presets/a_<32 hex>.png`. Источники и обновление каталога описаны в `img/avatar-decorations/README.md`.

Ширина Discord-плашки зависит от содержимого. Лимит видимых значков регулируется отдельно; остальные доступны через `+N`. Выбор значков свободный и не зависит от значков, полученных аккаунтом Discord.
